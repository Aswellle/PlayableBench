## 0. 现状事实（合并基线 main）

- 链路（spec 09 §1 修订）：手机浏览器 → 外部 relay（服务端不在本仓库）→ `webRemoteControlManager`（desktop main，1726 行）→ `web-remote-replayable` attachment → 窗口共享 Host → 同一 CLI 运行时。
- 已具备：HMAC-SHA256 challenge-response、`/ws` 强制 replayable、`/ws/host` 30s 一次性 capability、快照+对账恢复、QR 过期校验（阶段 1 最小修复：`isWebRemoteControlQrExpired`/TTL 5min/skew 2min）、单设备撤销入口、40+ 单元测试（8 个测试文件）。
- 缺口（裁决 SR-04，spec 09 §3/§4）：无设备注册表（单一配对凭证）、无 scope 分级（配对即全窗口权限）、无逐设备撤销/一键撤销全部、无设备绑定确认流、无命令幂等账本、无并发审批 CAS、无安全事件记录面；手机侧已有 workspace 列表/切换/任务读取，缺任务列表/审批卡片/暂停继续取消。
- relay 协议面在本仓库（packages/shared web-remote-control.ts，1055 行）；服务端不在本仓库，不能新增 relay 侧行为。
