## 2. 门禁对照（spec 16）

| 门禁 | 落点 |
|---|---|
| 摘要可追溯 | pb_feed_summaries.run_id/模型/时间/引用片段；S4 |
| 外部内容不能提升工具权限 | untrusted 分隔 + 模板 permissions ∩ registry 白名单 + 注入回归；S5 |
| 重复触发有幂等保护 | 研究启动幂等（活动 run 复用）；摘要缓存键唯一；capture→task 原始输入保留可重试；S3/S4/S2 |

## 3. 纪律

- 迁移只追加；冻结 SQL 不改；账本末位引用处（备份测试等）同步更新前先 grep 全库。
- 提交按切片多次提交；提交信息只述改动。
- 每切片：typecheck + lint + architecture:check --changed + 目标测试；收尾跑 services 全量。
